# ASH LINE v0.0.1

## First Combat Prototype

هذه النسخة تستهدف أول Combat Prototype على Android ARM64، وتشمل Player Movement وShooting و3 Weapons وEnemy AI وDamage/Death وCombat Test foundation وAndroid touch architecture وModular Content infrastructure.

## غير مشمول

لا تشمل النسخة المدينة الكاملة، أو Drone، أو Campaign، أو Final Graphics، أو Multiplayer، أو CDN Runtime، أو Google Play Asset Delivery Runtime.

## Build Status

تم تجهيز إعدادات Android ARM64 وBuild Scripts وAPK Verification، لكن لا يوجد APK مرفق حاليًا لأن Unreal Engine 5.4 وAndroid SDK/NDK غير متاحين في بيئة التنفيذ. يجب إكمال Compile/Cook/Package وInstall/Launch/Combat/Death/Restart على جهاز Android ARM64 قبل اعتبار الإصدار Release Candidate.
