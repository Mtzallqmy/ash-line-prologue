# Performance and Size Budget

| الفئة | الهدف |
|---|---:|
| Core Runtime + Code | ≤150 MB |
| Namar Prologue City | ≤170 MB |
| Characters + Animations | ≤60 MB |
| Weapons | ≤30 MB |
| Audio | ≤40 MB |
| UI + Fonts | ≤15 MB |
| Drone + VFX | ≤15 MB |
| Reserved overhead | ≤20 MB |
| **Hard target** | **≤500 MB** |

يجب قياس Build الحقيقي. عند تجاوز الهدف، يكتب التقرير أكبر 20 أصلًا أو حزمة بحسب الحجم قبل اتخاذ أي قرار حذف أو ضغط.
