# Prologue Mission Flow

| Mission | تعليم/هدف | نهاية المهمة |
|---|---|---|
| Mission 01 — Arrival | حركة، كاميرا، ركض، انحناء، تفاعل | الوصول إلى الساحة |
| Mission 02 — First Contact | إطلاق النار، إعادة التعبئة، الغطاء، الضرر، AI | تأمين النقطة العسكرية |
| Mission 03 — Eye Above | إطلاق Scout Drone، تحديد هدف، اشتباك قصير، Extraction | يظهر Prologue Complete |

المدة المستهدفة 15–25 دقيقة. لا تدخل ميزات Multiplayer أو مدينة ثانية أو Vehicles في Phase 1، لكن APIs الحالية لا تمنع إضافتها لاحقًا.
