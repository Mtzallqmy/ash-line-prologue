# جرد أصول هجرة ASH LINE إلى Godot

## نتيجة الفحص

لا يحتوي مجلد `Content/` في المصدر المرجعي على ملفات Unreal ثنائية (`.uasset` أو `.umap`) ولا على نماذج أو خامات أو أصوات بصيغ عامة قابلة للاستيراد مثل GLB أو FBX أو PNG أو WAV. يضم المجلد 26 ملفاً فقط: سبعة ملفات JSON قابلة لإعادة الاستخدام مباشرة وتسعة عشر ملف Markdown تصف المحتوى المقصود. لذلك لا توجد أصول مرئية أو صوتية يمكن استخراجها أو تحويلها من دون Unreal، ولن يُستخدم Unreal في هذا المسار.

## سجل النقل

| الأصل | صيغة المصدر | الصيغة الجديدة | الحالة | الإجراء |
|---|---|---|---|---|
| `weapon_catalog.json` | JSON | JSON | قابل للنقل | يُنسخ إلى `Godot/data/` ويغذي إحصاءات سلاح الـVertical Slice. |
| `health_config.json` | JSON | JSON | قابل للنقل | يُنسخ إلى `Godot/data/` ويغذي نقطة الصحة والضرر. |
| `mission_catalog.json` | JSON | JSON | قابل للنقل | يُنسخ إلى `Godot/data/` كأساس لهدف «القضاء على الأعداء». |
| `ai_archetype_catalog.json` | JSON | JSON | قابل للنقل | يُنسخ إلى `Godot/data/` كإعدادات افتراضية للعدو. |
| `input_asset_manifest.json` | JSON | JSON | قابل للنقل جزئياً | يبقى مرجعاً لأسماء الأوامر ثم تُعرّف الأوامر أصيلاً في `project.godot`. |
| `content_manifest.json` و`chunk_manifest.json` | JSON | JSON | مؤجل | يُحتفظ بهما كمرجع؛ لا يحتاجهما الـVertical Slice المحلي. |
| خرائط Namar وCombat Test | وصف Markdown فقط | مشهد Godot (`.tscn`) | يعاد إنشاؤه | تُنشأ ساحة اختبار ثلاثية الأبعاد خفيفة من أرضية وجدران وعوائق بدائية. |
| نموذج اللاعب والعدو | غير موجود | `CapsuleMesh` و`BoxMesh` | بديل مؤقت | أشكال بدائية ملوّنة؛ لا توجد نماذج قابلة للنقل. |
| السلاح والطلقات | غير موجود | عقد Mesh/Line برمجية | بديل مؤقت | سلاح بسيط مرئي وHitscan مع خط أثر قصير. |
| الخامات والإضاءة | غير موجود | `StandardMaterial3D` | يعاد إنشاؤه | ثلاثة ألوان أساسية وإضاءة اتجاهية واحدة لتقليل كلفة العرض. |
| صوت الإطلاق وVFX | غير موجود | لا أصل صوتي مؤقتاً | مفقود | يُحافظ على حدث الإطلاق والمنطق؛ تضاف أصول مرخصة لاحقاً. |
| واجهة HUD وأيقونات اللمس | غير موجود | `Control` و`Gradient` | يعاد إنشاؤه | واجهة نصية وأزرار دائرية قابلة للمس؛ أيقونات فنية مؤجلة. |

## قواعد التنفيذ

تستخدم النسخة الأولى أصولاً إجرائية داخل Godot، لا ملفات مولدة مموهة على أنها أصول إنتاجية. كل أصل فني أو صوتي نهائي سيحتاج مصدراً مرخصاً منفصلاً لاحقاً، بينما تبقى قواعد اللعب والبيانات المحمولة قابلة للاختبار الآن.
